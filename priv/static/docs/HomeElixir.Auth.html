    HomeElixir.Auth (home_elixir v0.1.0)

    Copy Markdown View Source

    Local accounts (Mnesia), in-memory sessions (ETS), and PBKDF2 password hashing via OTP :crypto — no external deps, so the hermetic Nix build is untouched.

    On start it seeds accounts from :home_elixir, :auth_users (username => password) and always ensures an admin: its password from that config, or a freshly generated one (printed to the log) when none is configured.

    A user logs in with a local password (login/2) or a Home Assistant token (login_ha_token/1), whose identity and role are resolved via HA's WebSocket auth/current_user (is_admin maps to the local admin role).
