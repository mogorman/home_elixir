    HomeElixir.NodeRedStatus (home_elixir v0.1.0)

    Copy Markdown View Source

    Tracks whether the Node-RED Companion integration is installed in Home Assistant. Probed once at startup (and re-checkable on demand from the admin page).

    Status is three-state:

    • :loaded — the integration is added & set up (its nodered/version websocket command is registered, which only happens once a config entry is loaded)
    • :absent — HA is reachable but the integration is not added/set up
    • :unknown — can't tell (no HA client, not connected yet, or a probe error)

    Only :absent changes behavior (the flow→Node-RED sync stops and device nodes go inert). :unknown keeps existing behavior so a slow or absent HA connection at boot never raises a false "missing" warning.
