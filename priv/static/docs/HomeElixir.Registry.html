    HomeElixir.Registry (home_elixir v0.1.0)

    Copy Markdown View Source

    Loads and unloads flows and tracks which are running.

    A flow is an Elixir module using HomeElixir.Flow. Loading it spawns a supervised process per node and wires them together; unloading tears it down.
