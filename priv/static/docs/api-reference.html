    Modules

    HomeElixir

    A Node-RED-style flow engine for Home Assistant, in Elixir.

    HomeElixir.Auth

    Local accounts (Mnesia), in-memory sessions (ETS), and PBKDF2 password hashing via OTP :crypto — no external deps, so the hermetic Nix build is untouched.

    HomeElixir.AuthGuard

    Wraps HomeElixir.Web and enforces a session on every route except the public ones (/login, /api/login, static assets, favicon). On success it assigns conn.assigns.user = {username, role} and hands the conn to HomeElixir.Web; on failure it redirects HTML requests to /login and answers /api/* with 401.

    HomeElixir.Config

    Layered, editable configuration for flows.

    HomeElixir.Dep

    Install external Hex dependencies at runtime, Livebook-style, without editing mix.exs.

    HomeElixir.EntityBrowser

    Build an Area > Device > Entity tree of Home Assistant entities, for the editor's entity browser. build/3 is pure and assembles the tree from three read-only HA lists; tree/0 fetches them from the shared HA client.

    HomeElixir.Examples

    Bundled example flows, kept in a separate read-only examples/ dir (outside the user's flows/ dir). They can be listed, viewed, and copied into the user's flows (verbatim) so they can be edited. They are never loaded or run in place.

    HomeElixir.Flow

    Declare a flow as an Elixir module.

    HomeElixir.FlowState

    Persistent per-flow state, namespaced by the calling flow's module.

    HomeElixir.FlowStore

    Discovers flow .ex files and loads/unloads them at runtime.

    HomeElixir.FlowsHA

    Exposes every flow as a switch in a single "Flows" device in Home Assistant, via the Node-RED Companion integration. Each switch's state is the flow's loaded state; toggling it in HA loads/unloads the flow.

    HomeElixir.HA

    Access to the shared, named HomeElixir.HA.Client.

    HomeElixir.HA.Client

    A client for the Home Assistant WebSocket API.

    HomeElixir.HA.LiveUpdate

    Send and dismiss Android/iOS Home Assistant companion Live Activities to a person's devices — the reusable core. Flows just call update/3 / dismiss/2.

    HomeElixir.HA.OAuth

    Home Assistant local OAuth (authorization code + PKCE).

    HomeElixir.HA.OAuthStrategy

    The OAuth2.Strategy.AuthCode flow, minus the Authorization: Basic header.

    HomeElixir.HA.PendingLogins

    Shared store for in-flight OAuth logins, keyed by the state value.

    HomeElixir.HA.Transport.Mint

    WebSocket transport backed by Mint + Mint.WebSocket.

    HomeElixir.Log

    In-memory ring buffer of recent log lines, fed by HomeElixir.LogHandler.

    HomeElixir.Msg

    A message flowing through a flow, Node-RED-style. payload is the primary value; topic and data carry metadata; extra fields live in data.

    HomeElixir.Node

    Behaviour for flow nodes.

    HomeElixir.NodeRedStatus

    Tracks whether the Node-RED Companion integration is installed in Home Assistant. Probed once at startup (and re-checkable on demand from the admin page).

    HomeElixir.Nodered

    Helpers for managing Node-RED-integration entities from Elixir.

    HomeElixir.Nodes.Device

    Presents a device (entity) to Home Assistant via the Node-RED integration and owns its state bidirectionally.

    HomeElixir.Nodes.Function

    Applies a function to each message. Config is fun: &Mod.fun/1 (a remote function). It receives the HomeElixir.Msg and returns a new Msg (or a raw value, wrapped as payload), or nil to drop the message.

    HomeElixir.Nodes.Inject

    Passthrough source node: re-emits each incoming message unchanged. Use it as the entry point of a flow that starts from an external trigger (a web button via the ui: config) rather than from an HA event.

    HomeElixir.Nodes.Logger

    Logs each incoming message and produces no output. A debug/observation node (the Node-RED debug equivalent), useful as a flow endpoint and for e2e.

    HomeElixir.Nodes.Schedule

    Source node: fires on wall-clock times given by a 5-field cron expression (e.g. "*/2 * * * *" every 2 minutes, "0 15 * * 1" Monday at 3pm).

    HomeElixir.Nodes.Service

    Sink node: calls a Home Assistant service when a message arrives.

    HomeElixir.Nodes.Sink

    Records every incoming message (most recent first). Useful as a flow endpoint and for tests; read it back via HomeElixir.Registry.node_state/2.

    HomeElixir.Nodes.StateChanged

    Source node: emits a message when a Home Assistant entity's state changes.

    HomeElixir.Registry

    Loads and unloads flows and tracks which are running.

    HomeElixir.Terminal

    Cowboy WebSocket handler that gives the browser a real IEx bridged over xterm.js.

    HomeElixir.Web

    Web UI + JSON API for managing flows: a list page, an inline-highlighted editor for flow files, and a live-updating log page.
