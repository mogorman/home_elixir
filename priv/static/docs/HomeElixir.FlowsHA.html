    HomeElixir.FlowsHA (home_elixir v0.1.0)

    Copy Markdown View Source

    Exposes every flow as a switch in a single "Flows" device in Home Assistant, via the Node-RED Companion integration. Each switch's state is the flow's loaded state; toggling it in HA loads/unloads the flow.

    On every sync (at boot, after any create/delete/archive/restore, and on a timer) the Flows device is reconciled against the live flow set: HA entities with no matching non-archived flow are removed, and switches for current flows are (re)discovered. The device's current switches are read from HA's REST /api/states (the reliable source — the WS get_states list does not return these entities), so orphaned entities are cleaned up even if they predate this process's memory of them.

    A no-op when HA is not configured.
