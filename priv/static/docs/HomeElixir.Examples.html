    HomeElixir.Examples (home_elixir v0.1.0)

    Copy Markdown View Source

    Bundled example flows, kept in a separate read-only examples/ dir (outside the user's flows/ dir). They can be listed, viewed, and copied into the user's flows (verbatim) so they can be edited. They are never loaded or run in place.

    Summary

    Functions

    copy(name)

    Copy an example flow, verbatim, into the user's flows dir under the same base name. Returns {:ok, name}, or {:error, :exists} / {:error, :not_found}.

    list()

    All example flows as %{name, path}, sorted by name.

    source(name)

    The source of one example flow, or {:error, :not_found}.
